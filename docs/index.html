AshlarOS

An Arch-based distribution: plain Arch underneath, CachyOS's v3-optimised repositories layered over it, linux-cachyos, chwd for hardware detection, systemd-boot, and a sway desktop.

Download

ashlaros.iso  — x86_64 only. The package stack is x86_64_v3, which needs AVX2: machines older than 2013 cannot run it.

Every build, with checksums: iso.ashlaros.download

UEFI only. The image carries one boot path, systemd-boot, and no BIOS one. A machine in legacy or CSM mode will not see it as bootable at all — switch the firmware to UEFI.

Write it to a stick with dd or cp straight to the device. The image is a hybrid ISO and needs no help; a writer that repacks it can leave the EFI partition unbootable.

The repository, on an existing Arch system

The ashlaros repository is dual-arch. There is no ARM ISO — CachyOS publishes no ARM repositories to build one from — but the packages install on Arch Linux ARM just as well. 

curl -fsSL https://packages.ashlaros.download/ashlaros.gpg -o /tmp/ashlaros.gpg
sudo pacman-key --add /tmp/ashlaros.gpg
sudo pacman-key --lsign-key "$(gpg --show-keys --with-colons /tmp/ashlaros.gpg |
  awk -F: '/^fpr:/ {print $10; exit}')"

printf '[ashlaros]\nSigLevel = Required DatabaseRequired\nServer = https://packages.ashlaros.download/$arch\n' |
  sudo tee -a /etc/pacman.conf

sudo pacman -Sy ashlaros-keyring ashlaros-mirrorlist ashlaros-settings

What it is not

  • Not Manjaro. No mhwd, no Manjaro rebuilds, no calamares — plain Arch provides what those did, and chwd replaces mhwd.
  • Not for pre-Haswell CPUs, for the reason above.
  • Not an ARM ISO.
